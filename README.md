# Frameworks de prompt engineering (2026)

Collection structuree de frameworks de prompt engineering pour les principaux modeles d'IA generative (Claude, GPT, Gemini), avec des exemples concrets adaptes aux cas d'usage metier.

## Contenu

Le fichier `frameworks-prompt-engineering.json` contient :
- 12 frameworks de prompt engineering documentes
- Pour chaque framework : nom, description, structure, cas d'usage
- Exemples concrets pour chaque framework (RH, marketing, juridique, finance, formation)
- Compatibilite par modele (Claude, GPT-4, Gemini)

## Frameworks inclus

1. **CRAFT** : Context, Role, Action, Format, Tone
2. **RISEN** : Role, Instructions, Steps, End goal, Narrowing
3. **CO-STAR** : Context, Objective, Style, Tone, Audience, Response
4. **RACE** : Role, Action, Context, Expectations
5. **SCRIBE** : Situation, Complication, Resolution, Information, Benefit, Evaluation
6. **Chain of Thought** : decomposition en etapes de raisonnement
7. **Few-Shot** : apprentissage par exemples
8. **Tree of Thoughts** : exploration de branches de raisonnement
9. **ReAct** : raisonnement + action iteratifs
10. **Self-Consistency** : generation multiple + vote majoritaire
11. **Constitutional AI** : cadrage ethique du prompt
12. **Meta-Prompting** : prompt qui genere des prompts
